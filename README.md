# Asansör Sessizliği Çevirmeni

> Resmî, bilimsel, biraz da fazla ciddi bir protokol yazılımıdır.

Bu depo, asansör kabininde kimsenin konuşmadığı o kısa süreyi Türkçe varoluşçu monoloğa çevirmek için kurulmuştur. Proje şaka değildir. Şaka gibi durması, şakanın ciddiyetinden kaynaklanır.

## Neden bu yazılım var?

Çünkü asansör sessizliği evrensel bir insan hakları meselesidir. Kimse o 8-14 saniyeyi belgelemez. Belgelemeyince tarih yazılmaz. Tarih yazılmayınca asansör kazanır.

Bu yazılım asansörü yenmez. Sadece sessizliği Türkçe'ye çevirir.

## Kurulum

Python 3 yeter. Başka bir şey istemez. Asansör de istemez ama yine de bineriz.

```bash
git clone https://github.com/Tentivory/asansor-sessizligi-cevirmeni.git
cd asansor-sessizligi-cevirmeni
python3 cevirmen.py
```

## Kullanım senaryosu

1. Asansöre binin.
2. Kimseyle göz göze gelmeyin.
3. Programı çalıştırın.
4. Süreyi girin.
5. Çıkan cümleyi içinizden okuyun.
6. Katınıza inin. Hayata devam edin ama biraz daha bilge olun.

## Mimari

- Rastgele seçim algoritması vardır.
- Bekleme noktaları vardır. Hızlı sonuç ayıptır.
- Hiçbir harici API yoktur. Asansör zaten yeterince dış bağımlılık.

## Sık sorulan sorular

**Bu gerçekten çalışıyor mu?**  
Evet. `python3 cevirmen.py` yazın. Sessizlik çıktıya dönüşür.

**Neden Türkçe?**  
Çünkü sessizlik evrenseldir ama iç çekiş Türkçe daha iyi durur.

**Siyasi midir?**  
Hayır. Asansör nötrdür. Herkes aynı kabine biner. (Bu cümle tesadüftür.)
